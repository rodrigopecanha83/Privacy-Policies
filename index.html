Privacy Policies

Software, Extensions and Tools Developed by Rodrigo Peçanha

Welcome to the official privacy portal. All applications listed below are engineered with a strict Privacy-First philosophy: zero personal data collection, zero third-party telemetry, zero external servers, and strictly local, in-browser execution.

Copy Google Maps Plus Code

English / Multilingual

Chrome Extension that reads GPS coordinates (latitude, longitude) from the clipboard, generates the corresponding Open Location Code (Plus Code) locally, and copies it back with visual toast confirmation.

Change Case

English / Multilingual

Text conversion Chrome extension with 12 distinct casing styles (UPPERCASE, lowercase, Title Case, Chicago Style, kebab-case, CamelCase, etc.) and instant clipboard integration.

ScreenShot Turbo

English / Multilingual

One-click screen capture extension designed to take immediate PNG screenshots of the visible browser area and download them automatically without user friction.

Coordenadas do Cadastro

Português — Uso Pessoal

Extensão para consulta, cadastro e higienização de coordenadas geográficas de imóveis vinculadas a inscrições imobiliárias via armazenamento local (ferramenta interna).

Copiar Código Externo 1Doc

Português — Uso Pessoal

Extensão utilitária para localização e cópia automatizada do número de processo externo em páginas do sistema 1Doc.
