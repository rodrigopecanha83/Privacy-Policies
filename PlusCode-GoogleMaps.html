Privacy Policy — Copy Google Maps Plus Code

Last Updated: October 28, 2026

This document outlines the privacy practices and data protection commitments for the Google Chrome extension "Copy Google Maps Plus Code" (hereinafter referred to as the "Extension").

Key Summary: The Extension operates 100% locally on your computer. It does not collect, track, transmit, or monetize any personal data, geographic locations, browsing history, or clipboard contents.

1. Single Purpose Policy

The single purpose of this Extension is to allow users to convert geographic coordinates (latitude and longitude) copied to their system clipboard into an official Google Maps Plus Code (Open Location Code) with a single click, automatically copying the result back to the clipboard and displaying an on-screen toast confirmation on the active tab.

2. Data Collection and Processing

The Extension does not operate external application servers, databases, or analytics engines. All computational processes take place entirely in-memory within your local browser:

  • Clipboard Reading: Upon the user clicking the extension icon, the Extension inspects text in the clipboard strictly looking for a numeric coordinate pattern (e.g., -22.9068, -43.1729).
  • Local Computation: Coordinates are decoded and encoded into a Plus Code via the bundled, offline Google OpenLocationCode library.
  • Clipboard Writing: The resulting Plus Code is copied back to your system clipboard so you can immediately paste it.
  • Zero Retention: After the conversion completes, the memory buffer is discarded immediately. No coordinate data is ever saved or transmitted.

3. Technical Permissions Justifications

To deliver its features within the Google Chrome Manifest V3 environment, the Extension requests the following minimum set of permissions:

  • clipboardRead: Strictly required to read the latitude and longitude coordinates that the user previously copied to the clipboard, executed exclusively when clicking the extension icon.
  • clipboardWrite: Required to automatically write the generated Google Maps Plus Code back to the system clipboard for immediate pasting.
  • activeTab: Grants temporary access exclusively to the active tab where the user clicked the action button to display a non-intrusive on-screen toast notification.
  • scripting: Executes the conversion routine and injects the ephemeral feedback notification into the active tab on-demand.

4. Absence of Remote Code and Third Parties

  • The Extension does not load or execute remote code, strictly adhering to Google Chrome's Manifest V3 security policies.
  • All logic, icon assets, and the OpenLocationCode library are bundled locally inside the extension archive.
  • No data is ever sold, transferred, or shared with third parties or advertising networks.

Este documento descreve as práticas de privacidade e proteção de dados da extensão para Google Chrome "Copiar Plus Code do Google Maps" (doravante denominada "Extensão").

Resumo Fundamental: A Extensão funciona 100% de forma local no seu computador. Ela não coleta, não rastreia, não transmite e não monetiza nenhum dado pessoal, localização geográfica, histórico de navegação ou conteúdo da área de transferência.

1. Política de Único Propósito

A Extensão tem como único propósito permitir que o usuário converta coordenadas geográficas (latitude e longitude) copiadas na área de transferência em um Plus Code (Open Location Code) do Google Maps com um único clique, copiando o resultado de volta e exibindo um aviso visual (toast) na aba ativa.

2. Coleta e Processamento de Dados

A Extensão não possui servidores externos, bancos de dados ou ferramentas de métricas. Todo o processamento ocorre inteiramente em memória no seu navegador:

  • Leitura da Área de Transferência: Ao clicar no ícone da extensão, ela inspeciona o texto do clipboard estritamente à procura do padrão numérico de coordenadas (ex: -22.9068, -43.1729).
  • Cálculo Local: As coordenadas são processadas pela biblioteca oficial OpenLocationCode empacotada localmente e de forma offline.
  • Gravação no Clipboard: O Plus Code resultante é copiado para a área de transferência para colagem imediata.
  • Zero Retenção: Após a conclusão da conversão, as informações são descartadas da memória imediatamente. Nenhum dado é salvo ou enviado a servidores.

3. Justificativas Técnicas de Permissões

Para executar suas funções no ambiente Manifest V3 do Google Chrome, a Extensão requer apenas o conjunto mínimo de permissões:

  • clipboardRead: Necessária exclusivamente para ler as coordenadas geográficas copiadas previamente pelo usuário no momento em que ele clica no ícone.
  • clipboardWrite: Necessária para gravar automaticamente o Plus Code gerado na área de transferência.
  • activeTab: Concede acesso temporário exclusivamente à aba em que o usuário acionou a extensão para exibir o toast visual de confirmação.
  • scripting: Executa pontualmente a rotina de conversão e a injeção do aviso na tela sob demanda do usuário.

4. Ausência de Código Remoto e Terceiros

  • A Extensão não carrega nem executa código remoto, em total conformidade com as diretrizes do Manifest V3 da Chrome Web Store.
  • Toda a lógica e bibliotecas estão 100% empacotadas no arquivo local da extensão.
  • Nenhum dado é comercializado, compartilhado ou transferido para terceiros ou anunciantes.
