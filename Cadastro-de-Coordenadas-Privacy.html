Política de Privacidade — Coordenadas do Cadastro Uso Interno / Pessoal

Última atualização: 28 de outubro de 2026

Aviso: Esta extensão é de uso pessoal e interno (não listada publicamente na Chrome Web Store). Seu objetivo é otimizar rotinas de trabalho operacional específicas.

Este documento descreve as práticas de privacidade da extensão "Coordenadas do Cadastro" (doravante "Extensão"). A sua privacidade e a segurança dos dados manipulados são prioridades absolutas.

Resumo de Privacidade: A Extensão funciona 100% de forma local. Ela não coleta, não monitora, não transmite e não compartilha dados com nenhum servidor externo. Todos os cadastros e dados permanecem no armazenamento local do navegador (chrome.storage.local).

1. Finalidade da Extensão

A Extensão tem como finalidade exclusiva automatizar a busca, consulta, cadastro e atualização de pares de coordenadas geográficas atreladas a números de inscrição imobiliária, copiando o resultado para a área de transferência do usuário e permitindo a geração de backups locais em arquivo JSON.

2. Coleta e Armazenamento de Dados

  • Armazenamento Local (chrome.storage.local): A base de dados com as inscrições e suas respectivas coordenadas fica salva exclusivamente no perfil do navegador do usuário no dispositivo local.
  • Backup e Restauração: A exportação gera um arquivo JSON salvo na pasta de downloads do usuário, sob seu controle direto. A importação lê apenas o arquivo selecionado manualmente pelo operador.
  • Área de Transferência: A leitura do clipboard é acionada unicamente quando o usuário clica para buscar ou colar dados. Apenas o texto do número de inscrição ou coordenada é processado.
  • Zero Rastreamento Externo: Nenhuma informação é enviada a servidores remotos, serviços de analytics ou terceiros.

3. Permissões Requeridas e Justificativas Técnicas

  • storage: Necessária para armazenar localmente o banco de dados de inscrições imobiliárias e coordenadas no navegador do usuário.
  • clipboardRead: Necessária para ler o número de inscrição ou coordenada copiada pelo usuário ao acionar a busca com um clique.
  • clipboardWrite: Necessária para gravar a coordenada correspondente na área de transferência para colagem rápida.
  • activeTab e scripting: Permitem a captura automatizada da coordenada geográfica exibida na aba ativa quando acionada pelo operador.
  • downloads: Necessária para permitir o download do arquivo de backup (JSON) gerado localmente pelo usuário.

4. Ausência de Código Remoto

Todo o código-fonte da Extensão é estático e local, respeitando os padrões de segurança do Manifest V3 do Google Chrome. Não há carregamento dinâmico de scripts ou bibliotecas remotas.
